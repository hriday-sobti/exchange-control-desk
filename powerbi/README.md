# Power BI Semantic Model & Report Documentation

This folder contains all artifacts required to import, model, style, and visualize the **Exchange Control Desk** dataset in Microsoft Power BI Desktop.

---

## 1. Directory Contents

* **`measures/measures.dax`**: Complete library of DAX measures categorized into functional folders:
  - `01_Executive_KPIs` (`[Total Transactions]`, `[Total GTV]`, `[Success Rate %]`, `[Fee Revenue]`, etc.)
  - `02_Risk_and_Anomalies` (`[Total Anomalies Flagged]`, `[Open P1 Incidents]`, `[Total Exposure at Risk]`, etc.)
  - `03_Data_Quality` (`[Data Quality Score]`)
  - `04_Time_Intelligence` (`[GTV Prior Period]`, `[GTV Growth %]`)
* **`theme/theme.json`**: Enterprise dark navy visual theme (`#0F172A` background, modern financial color palette) matching institutional risk control desks.
* **`power_query/power_query_m.txt`**: Ready-to-paste Power Query M code for seamless ingestion and type enforcement of the dimensional exports.
* **`exports/`**: Clean CSV and Parquet files generated by the master pipeline:
  - `dim_dates.csv`
  - `dim_users.csv`
  - `dim_assets.csv`
  - `fact_transactions.csv`
  - `fact_market_ticks.csv`
  - `fact_anomalies.csv`
  - `fact_incidents.csv`

---

## 2. Setting Up in Power BI Desktop (Step-by-Step)

1. Launch **Power BI Desktop**.
2. Go to **View -> Themes -> Browse for themes** and select `powerbi/theme/theme.json`.
3. Import the tables from `powerbi/exports/` using Power Query (or use DuckDB ODBC/PostgreSQL connector).
4. Verify relationships in **Model View**:
   - `dim_dates[date_key]` $\rightarrow$ `fact_transactions[date_key]` (1-to-many, single direction)
   - `dim_users[user_id]` $\rightarrow$ `fact_transactions[user_id]` (1-to-many, single direction)
   - `dim_assets[asset_id]` $\rightarrow$ `fact_transactions[asset_id]` (1-to-many, single direction)
   - `fact_anomalies[anomaly_id]` $\rightarrow$ `fact_incidents[anomaly_id]` (1-to-1)
5. Create a new measure table and paste the measures from `powerbi/measures/measures.dax`.
6. Follow the visual layout specified in `docs/dashboard_guide.md` across the 5 report pages:
   - **Page 1:** Executive Overview
   - **Page 2:** Market & Platform
   - **Page 3:** Transaction & User Behavior
   - **Page 4:** Anomaly / Incident Desk
   - **Page 5:** Data Quality & Monitoring
